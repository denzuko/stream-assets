Rules and borders

Centered rule (38% width)

No grid lines. No box shadows. No gradients. No border-radius greater than 4px.
Structure comes from whitespace and dotted rules only.

Using brand.css
/* Import canonical tokens */
@import url('https://denzuko.github.io/stream-assets/css/brand.css');

/* Or self-host */
<link rel="stylesheet" href="{{ "/css/brand.css" | relURL }}">

brand.css exports all CSS custom properties. Import it at the top of any project stylesheet.

Usage — do and don't
Do
Use dotted rules for structure
Use whitespace as layout
Use Share Tech Mono for all labels
Use cream/ink as the primary pair
Use the eye/lens mark as the site mark
Use the blinking cursor ▮ as punctuation
Use green/amber/red for monitoring only
Invert the mark for dark mode
Don't
Grid lines as background texture
Gradients anywhere
Drop shadows
Border-radius over 4px
Cyberpunk / neon palette (except off-air)
Borrowed institutional identity
